## HTML Buttons (Botones)

Los botones son elementos fundamentales para que el usuario pueda interactuar con tu página. Sin ellos, no podríamos enviar formularios, iniciar juegos o activar funciones especiales.
En HTML, un botón es un elemento en el que se puede hacer clic
. Aunque por defecto tienen un aspecto gris y sencillo, su verdadero potencial aparece cuando les damos estilo.

### Conceptos Clave:

Interacción: Su función principal es ejecutar una acción cuando el usuario los presiona
.
Estilización con CSS: Puedes transformar un botón aburrido en uno moderno cambiando su color de fondo, el color del texto, el tamaño y los bordes
.
Efectos de Hover: Es posible hacer que el botón cambie de color o crezca un poco cuando pasas el cursor sobre él, lo que mejora mucho la experiencia del usuario
.
Grupos de Botones: HTML y CSS permiten alinear varios botones juntos para crear menús o barras de herramientas

# Tipos de botones
El typeatributo define qué hace un botón al hacer clic. Hay tres tipos de botones:

type="button"- Un botón normal en el que se puede hacer clic (no hace nada por defecto)
type="submit"- Envía un formulario
type="reset"- Restablece todos los campos del formulari

## HTML IFrames (Marcos Flotantes) 🖼️

Imagina que quieres mostrar un video de YouTube, un mapa de Google o incluso otra de tus páginas web dentro de tu sitio actual sin que el usuario tenga que irse a otro enlace. Para eso sirven los IFrames.
Un IFrame (Inline Frame) se utiliza para mostrar una página web dentro de otra página web
. Funciona como una "ventana" o un marco que incrusta contenido externo.

### Conceptos Clave:

Incrustación: Permite traer contenido de otras fuentes (como videos o aplicaciones) y mostrarlo directamente en tu diseño
.
Atributos de Control: Puedes decidir qué tan grande o pequeña será esa "ventana" ajustando su altura (height) y anchura (width)
.

Atributo src: Es la parte más importante, ya que indica la dirección (URL) de la página que quieres mostrar dentro del marco
.
