# div, class y id en html

## div
un div es un contenedor invisible, agrupa otros elementos html 
fuerza saltos de linea

los ppodemos ubicar de diferente forma en la pantalla, con 4 formas principales

## class
se usa para especificar una clase y varios elementos pueden usar una misma clase y todos tendran ese mismo atributo que se especifique en la clase al inicio del codigo

## id
se parece a class pero es un identificador unico, se usa un "#" para señalar cada id
